# SOS-Management-Portal
# 🎓 SOS – School of Skills Management Portal

A simple and modern **School Management Portal** built with **Python and Streamlit**.

The application helps manage students, courses, faculty members, fees, reports, and institution data through an easy-to-use web interface.

## 🚀 Features

* 📊 **Dashboard**

  * Total students
  * Active courses
  * Revenue collected
  * Pending fees
  * Student overview

* 📚 **Course Management**

  * Add and manage courses
  * View course information
  * Track student enrollment

* 👨‍🎓 **Student Management**

  * Add and manage students
  * Assign students to courses
  * Track student fee payments

* 💰 **Fee Management**

  * Record paid fees
  * Calculate pending dues
  * Track total revenue

* 👨‍🏫 **Faculty Management**

  * Add faculty members
  * Manage subjects
  * Store faculty contact information

* 📈 **Reports**

  * Students per course
  * Revenue per course
  * Visual charts using Streamlit

* ⚙️ **Settings**

  * View institution details
  * Local data management
  * Reset demo data

* 🔐 **Admin Login**

  * Secure admin access screen
  * Login/logout functionality

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/SOS-Management-Portal.git
```

### 2. Open the project folder

```bash
cd SOS-Management-Portal
```

### 3. Install dependencies

```bash
pip install streamlit pandas
```

Or, if you have a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run sos_management_portal.py
```

The application will open in your browser.

## 💾 Data Storage

The application stores its data locally in:

```text
sos_data.json
```

This allows course, student, faculty, and fee information to persist between application sessions.

## 📊 Reports

The Reports section provides visual information including:

* Students enrolled in each course
* Revenue generated by each course

Charts are generated using Streamlit.

## 🎯 Project Objective

The goal of this project is to create a lightweight management system for a School of Skills that simplifies administrative tasks and provides a centralized interface for managing academic and financial information.
